Termux Background Picker

Checking Termux...

Requires Termux Monet with Background Image enabled under Settings → Termux → Termux Style. The companion uses Monet’s documented wallpaper interface. Upstream Termux does not support wallpaper rendering. Device qualification is still required.

First-run setup

Install and open Termux Monet with RUN_COMMAND support (Termux API 0.109 or newer). Enable Background Image in its settings before Apply (and again after Reset if Monet disables it). Install the DEB from this release inside Termux: dpkg -i ./termux-background_1.1.0_all.deb (install dependencies with pkg install termux-tools file coreutils). Add allow-external-apps=true to ~/.termux/termux.properties, then run termux-reload-settings. This enables authorized external apps to execute commands with your Termux privileges. Authorize this app, then run diagnostics. Termux:API is not required. No code is downloaded or installed automatically.

Images: PNG/JPEG, up to 20 MiB and 40 megapixels. Transfers use a resized JPEG up to 120 KiB; preview shows the prepared image. Opacity uses a black wallpaper overlay. Blur and scroll animation are unsupported by Monet.
